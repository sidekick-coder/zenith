# Database

For database interactions you can use the `database` facade.

It is a instance of kyseley so you can use all the methods provided by kyseley to interact with the user database.

```ts 
import { database } from '@sidekick-coder/zenith-kit/server'

// Get all users
const users = await database
    .selectFrom('users')
    .selectAll()
    .execute()
```
